# Smart Expense Tracker

A **React JS** application to track daily expenses and incomes, categorize them, filter and sort entries, and visualize spending using charts. The app uses **localStorage** for data persistence, **TailwindCSS** for styling, and **Recharts** for visualizations.

---

## Demo

You can deploy this project on **Netlify** or **Render**.  

---

## Features

### Expense Management
- Add, view, and delete expenses.
- Categorize expenses: Food, Travel, Bills, Others.
- Optional notes for each expense.
- Filter by category, date range, and amount range.
- Sort by most recent or highest amount.

### Income Management
- Add, view, and delete income entries.
- Optional notes for each income.

### Dashboard / Analytics
- Shows **Total Income**, **Total Expenses**, and **Net Balance**.
- Category-wise expense cards with icons and totals.
- Pie chart visualization for category-wise expense distribution.
- Updates dynamically as entries are added or removed.

### Persistent Storage
- Uses `localStorage` to save all expenses and incomes across browser sessions.

### Responsive UI
- Fully responsive with **TailwindCSS**.
- User-friendly forms with validation and error messages.
- Responsive charts using **Recharts**.

---

## Tech Stack

- **React JS** — Frontend framework.
- **TailwindCSS** — For modern, responsive styling.
- **React Router DOM** — For multi-page navigation.
- **Context API** — For global state management (expenses & incomes).
- **Recharts** — For charts and data visualization.
- **localStorage** — To persist data across sessions.
